# Türkü Defteri

Deyiş, nefes ve türkü sözleri, YouTube dinleme bağlantıları, kişisel repertuvar ve bağlama akort aleti. Reklamsız, çevrimdışı çalışır, veri toplamaz.

Adres: https://alierendemir.github.io/turku/

Geliştiren: Ali Eren Demir

- `app/` · Derleme gerektirmeyen PWA (HTML, CSS, JavaScript). Android'de Chrome'dan, iPhone'da Safari'den ana ekrana kurulur.
- `araclar/` · `app/data/turkuler.js` dosyasını Vikikaynak'tan üreten betikler.
- Sözler yalnızca telifi serbest metinlerden alınır. Günümüz sanatçılarının eserleri yalnızca YouTube bağlantısıyla yer alır.
